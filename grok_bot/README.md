# КОРОВАНЫ — Grok Bot

Статическая 3D-игра по ТЗ Кирилла. Three.js **0.168** с jsDelivr (ES modules), без сборки.
Злодея зовут **Владыка Морвейн**.

Играть: https://rai220.github.io/korovany/grok_bot/

Локально из корня репозитория (только http — `file://` модули не загрузит):

```bash
python3 -m http.server 8123
# http://localhost:8123/grok_bot/
```

Все пути внутри экспоната относительные и живут только под `grok_bot/`.

## Стороны

На старте выбери фракцию:

| Сторона | Суть |
|---|---|
| **Лесные эльфы** | Густой лес и деревянные хижины. Грабь корован на тракте (сначала стражу). Партизаны ходят набегом на форт. |
| **Охрана дворца** | Слушайся командира: приказ всегда на HUD. Защищай дворец от эльфов и Морвейна. |
| **Владыка Морвейн** | Старый форт в горах. Ты командир: `1` за мной, `2` держать форт, `3` штурм дворца. |

Четыре зоны без загрузок: эльфийский лес, дворец императора, людская деревня (лавка и лекарь), горы со старым фортом.

## Управление

| Клавиша | Действие |
|---|---|
| **WASD** | Ходьба |
| **Мышь** | Обзор (клик — захват указателя) |
| **Пробел** | Прыжок (на коляске нельзя) |
| **ЛКМ** | Удар. Можно отрубить руку, выколоть глаз, отсечь ногу |
| **V** | Вид от 1-го лица ↔ третье лицо |
| **E** | Обыск 3D-трупа, лавка, лекарь, ограбить корован |
| **B** | Перевязать рану бинтом из сумки |
| **1 / 2 / 3** | Морвейн: за мной / оборона форта / штурм дворца |
| **M** | Карта четырёх зон |
| **H** | Справка |
| **F5** | Сохранить в localStorage |
| **F9** | Загрузить |
| **Esc** | Отпустить мышь |

## Раны и лавка

- **Рука** — кровотечение. Без бинтов или лекаря умрёшь.
- **Глаз** — левая половина экрана чёрная.
- **Нога** — ползёшь. Купи **коляску** или **протез**.
- Трупы остаются в мире (3D) и обыскиваются на **E**.
- Лавка в деревне: меч, бинты, зелье, протезы, коляска.
- Лекарь: **20 золота** — остановить кровь и поднять здоровье.

## Лес и корован

Вдали деревья — плоские картинки (билборды). Когда подходишь, они становятся объёмными сетками. Сотни стволов в чаще.

По тракту едет корован: лошадь, повозка, ящики и двое стражников. Эльф может ограбить повозку, когда оба стража мертвы.

## Сохранение

`F5` пишет слот `korovany_grok_bot_v1` в localStorage браузера. `F9` поднимает позицию, раны, золото, инвентарь, корован и живых.
