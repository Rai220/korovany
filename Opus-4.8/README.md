# КОРОВАНЫ — вариант Opus 4.8

3Д-экшон от первого лица по легендарному ТЗ Кирилла. Браузерный, на **Three.js 0.160**
(через CDN + importmap), чистая статика — без сборки и без внешних ассетов
(все текстуры рисуются на canvas, поэтому никаких проблем с CORS на GitHub Pages).

## Как играть

Открыть `index.html` через любой http-сервер (ES-модули не работают с `file://`):

```bash
python3 -m http.server 8137
# затем http://localhost:8137/Opus-4.8/
```

Можно сразу прыгнуть за фракцию по ссылке: `?play=elf` · `?play=guard` · `?play=villain`.

### Управление
- **WASD** — ходьба, **мышь** — обзор (клик по экрану захватывает курсор)
- **ЛКМ** — удар (и грабёж корована), **Пробел** — прыжок, **Shift** — бег
- **E** — лавка торговца (рядом со зданием с золотой крышей у людей)
- **F** — приказ войскам: за злодея — «НА ДВОРЕЦ!», за остальных — «За мной!»
- **I** — инвентарь и состояние тела, **Q** — перевязать рану, **H** — выпить зелье
- **Esc** — пауза (там же сохранение/загрузка)

## Соответствие ТЗ

| Пункт ТЗ Кирилла | Реализация |
|---|---|
| 3Д-экшон, можно прыгать | Вид от 1-го лица, прыжок + гравитация, бег с выносливостью |
| Играть эльфами / охраной дворца / злодеем | 3 играбельные фракции со своими целями и спавном |
| Эльфы в лесу, деревянные домики, набигают солдаты и злодей | Зона леса с домиками на сваях; периодические набеги на лес |
| Можно грабить корованы | Повозки с охраной ходят по дорогам; бьёшь ЛКМ → золото |
| Густой лес; вдали деревья картинкой, вблизи 3-хмерные | **LOD-лес**: дальние — билборды-спрайты, в радиусе ~42 м превращаются в 3D-меши |
| Покупать как в Daggerfall | Лавка: оружие, броня, зелья, бинты, **протезы** |
| Враги 3-хмерные, труп тоже 3д | Гуманоиды из примитивов; трупы остаются и заваливаются на землю |
| Отрубить руку — без лечения умрёшь | Потеря руки → кровотечение (Q/H/протез спасают), удар слабеет |
| Выколоть глаз — пол-экрана не видно / протез | Затемнение половины экрана; глазной протез возвращает обзор |
| Нога — умрёшь / ползать / коляска / протез | Ползок (медленно), коляска (быстрее), протез (как новый, можно прыгать) |
| Охрана слушается командира, ходит на набеги, защищает дворец | Командир выдаёт приказы (патруль/набег/смотр) с наградой; защита при набеге |
| Злодей сам себе командир, ведёт войска на дворец | По **F** войска злодея идут на штурм; цель — перебить охрану дворца |
| 4 зоны: люди (нейтрал), дворец, эльфы, форт злодея в горах | Карта 1000×1000 с 4 зонами, дорогами и горами на востоке |
| Сохранятся можно | Сохранение/загрузка в `localStorage` (меню паузы) |

## Структура

```
Opus-4.8/
├── index.html        # разметка, importmap, HUD/оверлеи
├── style.css         # весь интерфейс
└── js/
    ├── main.js       # сцена, свет, игровой цикл, состояния
    ├── world.js      # террейн, 4 зоны, здания, дороги, коллизии
    ├── trees.js      # LOD-лес (билборд ↔ 3D)
    ├── player.js     # контроллер от 1-го лица, увечья и протезы
    ├── npc.js        # ИИ, бой, расчленёнка, трупы, корованы
    ├── factions.js   # цели фракций, приказы, набеги, штурм
    ├── ui.js         # меню, HUD, компас, магазин, инвентарь
    ├── textures.js   # текстуры на canvas
    └── save.js       # сохранение в localStorage
```
