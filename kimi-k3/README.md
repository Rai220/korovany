# КОРОВАНЫ — вариант Kimi K3

3D-экшон по легендарному ТЗ Кирилла («Я джва года хочу такую игру»).
Чистая статика: Three.js r160 лежит локально в `lib/`, ванильный JS (ES-модули),
без сборки — можно публиковать на GitHub Pages как есть.

## Запуск

```bash
# из корня репозитория
python3 -m http.server 8123
# открыть http://localhost:8123/kimi-k3/
```

Открывать нужно через HTTP (ES-модули не работают с `file://`).

## Что есть по ТЗ

- **Три играбельные стороны**: лесные эльфы, охрана дворца, Злой — у каждой своя
  цепочка заданий и финал.
- **4 зоны на одной карте**: 1 — люди (нейтрал, деревня с лавкой и лекарем),
  2 — дворец Императора (стены, башни, трон), 3 — густой лес эльфов
  (деревянные домики), 4 — горы Злого со старым фортом. Карта на клавишу **M**.
- **Густой лес с LOD**: вдали деревья — картинкой (спрайты), подходишь —
  преобразовываются в 3D.
- **Корованы**: телега с коровой ходит по тракту между деревней и дворцом
  под охраной. Убери охрану — грабь (E).
- **3D-враги и 3D-трупы**: гуманоиды с шарнирной анимацией, трупы остаются
  лежать (иногда без конечностей).
- **Прыжки** (Space), бег (Shift).
- **Как в Daggerfall**: золото, лавка (бинты, эликсиры, стальной меч, кольчуга),
  лекарь, жалование за приказы.
- **Расчленёнка**: руку могут отрубить (урон вдвое меньше, без перевязки
  истечёшь кровью), глаз выбить (пол-экрана темно), ногу отрубить (ползаешь).
  Лечение: бинт (H), лекарь за 50 зол.; протезы руки/глаза/ноги и коляска —
  в лавке. Враги тоже теряют конечности и ползают.
- **Приказы**: за стражника командир выдаёт приказы (пост у ворот, набег на
  рощу эльфов, поход на форт Злого); за Злого — военный стол: призыв
  прислужников, «за мной / ждать», штурм дворца с войском.
- **Сохранения**: кнопка в меню паузы + автосохранение при выполнении заданий
  (localStorage). Внутриэтапный прогресс (волны/склады) при загрузке
  начинается заново.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / Shift / Space | движение / бег / прыжок |
| Мышь | обзор (клик по экрану захватывает курсор) |
| ЛКМ | удар мечом |
| E | поговорить / грабить / использовать |
| H | перевязка / эликсир |
| M | карта четырёх зон |
| Esc | пауза / закрыть окно |

## Файлы

- `index.html`, `style.css` — каркас и оформление
- `js/world.js` — ландшафт, зоны, дороги, LOD-лес, постройки, коллайдеры
- `js/units.js` — модели персонажей, ИИ, бой, травмы, кровь, трупы
- `js/ui.js` — HUD, диалоги, лавка, карта, звук (WebAudio)
- `js/game.js` — кампании фракций, корованы, экономика, сохранения
- `js/main.js` — игрок (3-е лицо), ввод, состояния, цикл
- `lib/three.module.js` — Three.js r160
