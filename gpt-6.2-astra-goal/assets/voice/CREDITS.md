# Озвучка «Соляного тракта»

В игре 82 русские записи. У каждого из четырнадцати персонажей и рассказчиков свой исходный тембр. За воротами говорит Арда, на лесной тропе — Лиора, у мельницы — Эльда. Записи для сцены, всплывающей реплики и повторного прослушивания используют один и тот же текст. Эпилог собирается из решения суда, судьбы героя и последствий для мира.

Текст озвучен локально русскоязычными голосами модели **Silero v5 CIS Base Nostress**. Авторы распространяют веса этой модели по лицензии MIT. В статическую игру входят только записи, воспроизводимые через обычный браузерный аудиоэлемент. [Описание модели](https://github.com/snakers4/silero-models#v5-cis-base-models) · [Лицензия весов](../../tools/voice/LICENSE_CIS.txt)

Для озвучки использован авторский произносительный словарь с явным ударением. Он различает контекстные формы. У мельницы оседает мука́, в описании печати край в муке́, а уставший караванщик слышит звоно́к у воро́т. В записях выдержаны отдельные паузы между предложениями. MP3 содержат монофонический звук 48 кГц. [Произносительный словарь](../../tools/voice/stress-ru.txt) · [Сборка и акустическая проверка](../../tools/voice/README.md)
