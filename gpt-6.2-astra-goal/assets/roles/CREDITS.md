# Вступления трёх сторон

Сценарии «Пока горит окно», «Без сменного знака» и «Пустой обоз» написаны для «Соляного тракта». В сценах используются поселения, крепости, лица, одежда и движения из самой игры. Караульная книга, лесной фонарь, просыпанное зерно и полотнище с вышитыми вершинами поставлены специально для этих эпизодов. Три изображения в меню выбора стороны сняты в игровых сценах. Видеофрагмент боя у обоза записан в игре за лесного эльфа, с камерой за плечом. [Персонажи и костюмы](../characters/CREDITS.md)

Девять оригинальных реплик записаны в MP3 общей длительностью 53,3 секунды. Покадровая огибающая извлечена из окончательных записей и управляет движениями губ во время показа. Для Мары использован русский голос `ru_zinaida`, для Лиоры — `ru_ekaterina`, для Ивена — `ru_roman`, для Арды — `ru_albina`, для Гарта — `ru_alexandr`, для владыки — `ru_sibday`. Локальный синтез выполнен на Silero v5 CIS Base Nostress с явно указанными ударениями. [Текст и ударения](./lines.txt) · [Семейство моделей](https://github.com/snakers4/silero-models#v5-cis-base-models) · [Лицензия весов MIT](../../tools/voice/LICENSE_CIS.txt)

Готовые аудиофайлы независимо проверены классификатором meter2 с неразмеченным текстом. Во всех 79 многосложных произнесениях выбранная по звуку ударная гласная совпала со сценарием. Минимальная оценка выравнивания слова составила 0,633. [Описание автоматической проверки](../../tools/voice/README.md)

Для повторения из директории игры используются команды

```sh
python3 assets/roles/render.py /path/to/v5_cis_base_nostress.pt
python3 assets/roles/check_voices.py /path/to/meter /tmp/roles-stress.json
```
