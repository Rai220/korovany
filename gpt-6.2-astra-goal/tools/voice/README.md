# Сборка озвучки

Исходник сценария — массив `takes` в [voice.js](../../voice.js). Строки содержат говорящего, субтитр, имя файла и длительность. Для всех многосложных слов в [словаре](./stress-ru.txt) знак `+` ставится непосредственно перед ударной гласной. Сборка останавливается, если для нового слова отсутствует произносительная форма. Для «кто-нибудь» и «когда-то» сохраняется единое фонетическое слово.

Сценарии проверены с Python 3.11, PyTorch, NumPy и установленными `ffmpeg` и `ffprobe`. Модель весит около 92 МБ и нужна только при сборке. SHA-256 проверяется перед загрузкой в PyTorch. [Веса Silero](https://models.silero.ai/models/tts/ru/v5_cis_base_nostress.pt) · [Правила ручных ударений](https://github.com/snakers4/silero-models#v5-cis-base-models)

Из каталога игры выполните команду, указав путь к загруженной модели.

```sh
python3 tools/voice/render.py /path/to/v5_cis_base_nostress.pt
```

Чтобы перезаписать отдельные реплики, добавьте их имена, например `chronicler-01 wheelwright-02`. Сценарий создаёт MP3 в `assets/voice` и обновляет длительности в манифесте. Для новой партии записей измените значение `soundRevision` в `voice.js`, чтобы HTTP-кеш браузера увидел обновление.

## Проверка произношения

[check_stress.py](./check_stress.py) декодирует **готовые MP3** в монофонический сигнал 16 кГц. Внешняя модель wav2vec2 выравнивает буквы текста с аудиосигналом. Акустический классификатор meter2 оценивает каждую гласную и выбирает ударную. Сценарий передаёт классификатору слова без знаков ударения, затем сопоставляет его ответ со словарём. Для слабого выравнивания сохраняется неопределённый результат. [Описание и исходники meter2](https://huggingface.co/siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf/tree/c16b3af3db3095120efc1ebb73f6522442bcb3b1/meter) · [Русская акустическая модель](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-russian/tree/2329100508896c6d9b157019803ab5601e6f3406)

Для повторной проверки сохраните `meter2.py` и `head.pt` в отдельной папке. Нужны `torchaudio` с функцией `forced_align` и `transformers` 4.57.6. При первом запуске проверяющий сценарий meter2 загрузит веса wav2vec2 объёмом около 1,26 ГБ. В отчёте `target` и `observed` — номера гласных от нуля, `start` и `end` — время слова в записи.

```sh
python3 tools/voice/check_stress.py /path/to/meter /tmp/stress-report.json
```

Отдельный браузерный тест проверяет действительное воспроизведение, повтор, прерывание, громкость боевой музыки под голосом, настройки и составные эпилоги. [Тест в Chromium](../../tests/voices.cjs)

## Результаты для записей из поставки

Проверены 82 MP3 продолжительностью 8 минут 6 секунд. Среди 703 многосложных произнесений meter2 уверенно выровнял 701. У всех 701 выбранная ударная гласная совпала с разметкой. У «телег» после «шесть» и «её» в середине фразы выравнивание оказалось слабым. При снятии порога обе оценки указали на последний слог. Это автоматическая акустическая проверка.

| Слово | Запись | Интервал в звуке |
| --- | --- | --- |
| жернова́ | chronicler-01 | 0,14–0,66 с |
| мука́ | chronicler-01 | 3,52–3,88 с |
| возни́цы | chronicler-03 | 2,66–3,26 с |
| муке́ | chronicler-04 | 3,70–4,10 с |
| печа́ть | miller-04 | 12,72–13,34 с |
| сургучо́м | miller-06 | 4,28–4,88 с |
| головы́ | miller-06 | 6,84–7,32 с |

Дополнительно записаны три контрольные пары одним голосом с одинаковой вводной фразой. По звуку классификатор различил «за́мок / замо́к», «му́ка / мука́» и «стре́лки / стрелки́» во всех шести случаях. У первых команд Лиоры, Арды и Гарта темп при обычном воспроизведении составил 138, 143 и 117 слов в минуту. Разговор с Эльдой у мельницы длится 13,4 секунды, рассказ о печатях в судебном эпилоге — 11,7 секунды.
