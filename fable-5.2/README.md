# КОРОВАНЫ: джва года спустя — Fable 5.2

Браузерный 3Д-экшон по знаменитому ТЗ Кирилла. Игра целиком сделана моделью **Fable 5.2**.

Можно играть лесными эльфами, охраной дворца и злодеем. Можно грабить корованы.

## Запуск

Игра — статический сайт без сборки, точка входа — `index.html` в этой папке.

- **GitHub Pages:** достаточно опубликовать репозиторий; игра откроется по адресу `…/fable-5.2/`. Все пути относительные, внешних загрузок нет.
- **Локально:** нужен любой статический сервер, потому что браузеры не загружают ES-модули по `file://`:

  ```bash
  cd fable-5.2
  python3 -m http.server 8000
  # открыть http://localhost:8000/
  ```

Нужен браузер с WebGL 2 и мышь с клавиатурой. Проверялось в Chrome/Chromium.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD`, мышь | ходить, смотреть |
| `Shift` | бег (тратит выносливость) |
| `Пробел` | прыжок |
| `ЛКМ` | удар / выстрел |
| `ПКМ` | блок (спереди; спасает и от увечий) |
| `1` / `2` | ближнее / стрелковое оружие |
| `E` | говорить, торговать, обыскать труп, ограбить корован |
| `Q` | выпить зелье (или съесть хлеб) |
| `B` | перевязать рану бинтом |
| `I` | рюкзак, персонаж, характеристики, протезы |
| `M` | карта четырёх земель |
| `T` | приказы войску (за Злого) / журнал заданий |
| `V` | вид от первого / третьего лица |
| `F5` / `F9` | сохранить / загрузить |
| `Esc` | пауза |

## Что реализовано

**Мир.** Одна карта 1200×1200 и на ней 4 зоны: земли людей (нейтрал, город с рынком), зона Императора (дворец со стенами, башнями и донжоном), лес эльфов (густой лес, деревяные домики на сваях, Великое древо), горы Злого (старый полуразрушенный форт на плато). Зоны соединены дорогами через перекрёсток. Смена дня и ночи.

**Лес по ТЗ.** Около 4700 деревьев. Вдали деревья нарисованы картинкой (плоские спрайты, повёрнутые к камере), когда подходишь — преобразовываются в 3-хмерные деревья.

**Три стороны.**
- *Эльфы* — на деревню набигают солдаты дворца и злодеи; Владыка у Великого древа даёт задания (ограбить корован, убить лазутчиков, оборона, партизанская вылазка с отрядом).
- *Охрана дворца* — надо слушаться командира: он сам раздаёт приказы с таймером (дозор вокруг стен, поимка шпионов, оборона дворца, набег на эльфов или на Злого с отрядом). За выполнение — жалованье и звания, за невыполнение — штраф, потеря дисциплины и гауптвахта.
- *Злой* — сам себе командир: клавиша `T` отдаёт приказы войску (оборонять форт, «за мной», в атаку на дворец, в атаку на эльфов, засада на перекрёстке). Бойцов можно нанимать у барыги. На форт иногда нападают шпионы и партизаны эльфов.

Фракции воюют между собой и без участия игрока: отряды ходят в набеги по дорогам, гарнизоны пополняются. Победа — когда мертвы оба вражеских предводителя (Император, Владыка эльфов, Злой).

**Корованы.** По дорогам ходят корованы (телега, две коровы, охрана) четырёх владельцев. Перебил охрану — нажал `E` — забрал золото и товары. За грабёж людей портится репутация в нейтральной зоне: ополчение станет врагом, торговцы перестанут разговаривать (со временем остывают).

**Бой и увечья.** Мечи, кинжалы, секиры, луки со стрелами (баллистика), посох тьмы. Враги 3-хмерные, трупы тоже 3д — остаются лежать, их можно обыскать. Врагам можно отрубить руку или ногу (конечность отлетает и остаётся на земле, враг истекает кровью, без ноги — ползёт) и выбить глаз.

То же самое могут сделать с игроком:
- **рука** — кровотечение; если не перевязать и не вылечиться, умрёшь. Без руки нельзя стрелять из лука, без обеих — только пинаться;
- **нога** — кровотечение; дальше либо ползаешь, либо катаешься на коляске (в гору тяжело, прыгать нельзя), либо ставишь протез;
- **глаз** — не видно половину экрана (без обоих — темнота);
- протезы руки, ноги и глаза можно купить у мастера протезов и лекарей или достать с трупов.

**Как в Daggerfall (в миниатюре).** Золото, лавки с покупкой и продажей (оружейник, бронник, алхимик-лекарь, мастер протезов, купец, трактир с ночлегом, свои торговцы на каждой базе), рюкзак и экипировка, броня, опыт, уровни и три характеристики, репутация, платное лечение.

**Сохранение.** `F5` / `F9`, кнопки в паузе, автосохранение раз в 2,5 минуты, «Продолжить» в главном меню (хранится в `localStorage` браузера).

Мини-карта, карта мира, метки заданий, звук (синтезируется на лету, без файлов).

## Известные ограничения

- Сохраняется игрок (место, здоровье, увечья, вещи, золото, звание) и состояние мира (время, мёртвые предводители, приказ войску, нанятые бойцы). Расстановка NPC, корованы, идущие набеги и текущее задание при загрузке создаются заново.
- Домов внутри нет: торговцы стоят на улице, в здания зайти нельзя.
- ИИ ходит по прямой и обходит постройки простым манёвром; деревья для NPC проходимы. Иногда бойцы застревают у стен.
- После смерти можно «очнуться на базе», но отрубленное не отрастает — только протезы.
- Камера от третьего лица не учитывает стены и может заглядывать сквозь них.
- Управление только клавиатурой и мышью; сенсорных экранов и геймпадов нет.
- После выхода из паузы по `Esc` браузер может не сразу вернуть захват мыши — тогда нужно нажать «Продолжить» ещё раз.
- Имя злодею так и не придумано.

## Технологии

Чистый JavaScript (ES-модули) и [three.js](https://threejs.org/) r187, лежит в `lib/three.min.js` (лицензия MIT, `lib/THREE-LICENSE`). Вся графика, карта и звук создаются кодом — внешних картинок, моделей и аудио нет.

```
index.html      страница и разметка интерфейса
css/style.css   стили
js/data.js      фракции, предметы, география
js/world.js     ландшафт, постройки, лес с LOD, небо
js/entities.js  NPC, ИИ, стрелы, трупы, корованы
js/player.js    игрок, бой, увечья, протезы
js/director.js  население, набеги, приказы, задания
js/ui.js        HUD, карта, лавки, диалоги
js/main.js      цикл, ввод, сохранение, звук
```

Параметр `?test` в адресе включает режим без захвата мыши (для автоматических проверок).
