# КОРОВАНЫ — 3Д-экшон. Суть такова...

Браузерная 3D-игра по знаменитому ТЗ Кирилла («Я джва года хочу такую игру»).
Вариант от модели **Fable 5**. Чистая статика: Three.js с CDN, без сборки и зависимостей —
идеально для GitHub Pages.

## Как запустить локально

ES-модули не работают с `file://`, нужен любой статический сервер:

```bash
cd fable_5
python3 -m http.server 8123
# открыть http://localhost:8123/
```

## Как выложить на GitHub Pages

1. Создайте репозиторий и запушьте содержимое (папку `fable_5` или её содержимое в корень).
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/fable_5/`
   (или без `/fable_5/`, если содержимое папки лежит в корне репозитория).

Никакой сборки не требуется — Three.js загружается с jsdelivr через importmap.

## Соответствие ТЗ

| Требование | Реализация |
|---|---|
| Играть лесными эльфами, охраной дворца и злодеем | Три фракции на выбор в главном меню |
| Эльфы в лесу, домики деревянные | Деревня из деревянных домиков в густом лесу (зона 3) |
| Набигают солдаты дворца и злодеи | Периодические набеги волнами с баннером «НАБИГАЮТ!!!» |
| Можно грабить корованы | Корованы ходят по дороге; перебейте охрану и жмите [E] |
| Лес густой | ~540 деревьев в зоне эльфов |
| [1] Вдали деревья картинкой, вблизи преобразовываются в 3-хмерные | THREE.LOD: спрайт дальше 80 м, 3D-модель ближе |
| Можно покупать и т.п. возможности как в Daggerfall | Лавка в деревне людей: зелья, бинты, оружие, протезы, коляска |
| Враги 3-хмерные, и труп тоже 3д | Лоу-поли гуманоиды, трупы остаются лежать в мире |
| Можно прыгать и т.п. | Пробел (если ноги в строю) |
| Охрана: слушаться командира, защищать дворец, набеги | Командир выдаёт приказы по циклу: патруль, оборона, набег на эльфов, шпион, вылазка к форту. Платят жалование |
| Злодей: сам себе командир, приказы войскам, атака на дворец | [T]/[G]/[Y] — приказы войску, найм бойцов, штурм дворца, победа на троне |
| Злодей (имя я не придумал) | Имя вводит игрок; для других фракций он «Злодей (имя не придумано)» |
| 4 зоны: люди (нейтрал), император (дворец), эльфы, злой (горы, старый форт) | Карта 800×800 м, четыре квадранта + миникарта |
| Отрубить руку — если не вылечат, умрёт | Кровотечение до смерти; бинт [B], лекарь, протез руки |
| Выколоть глаз — пол-экрана не видно, или протез | Половина экрана чернеет; «Волшебный глаз» в лавке |
| Ногу: умрёшь / ползать / коляска / протез (самое хорошее) | Все четыре варианта реализованы |
| Сохраняться можно | [K] или меню паузы (localStorage) |

## Управление

- **WASD** — движение, **Shift** — бег, **Пробел** — прыжок
- **ЛКМ** — атака, **1** — меч, **2** — лук
- **E** — взаимодействие, **Q** — зелье, **B** — бинт
- **T / G / Y** — приказы войску (Злодей)
- **K** — быстрое сохранение, **Esc** — пауза, **H** — справка

## Структура

```
fable_5/
├── index.html      — страница, меню, HUD-разметка
├── style.css       — стили
└── js/
    ├── main.js     — игровой цикл, ввод, склейка систем
    ├── world.js    — рельеф, 4 зоны, LOD-деревья, постройки
    ├── npc.js      — ИИ, фракции, увечья NPC, корованы
    ├── player.js   — игрок, бой, система увечий и протезов
    ├── quests.js   — приказы, набеги, штурм, победа
    ├── ui.js       — HUD, миникарта, лавка, звук (WebAudio)
    └── save.js     — сохранения (localStorage)
```
