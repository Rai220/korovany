# Корованы: Четыре земли

Самостоятельный браузерный 3D-экшен по легендарному ТЗ Кирилла. Игра запускается как обычный статический сайт и подходит для GitHub Pages.

## Запуск

```bash
python3 -m http.server 4173 -d gpt-5.6-sol
```

Затем откройте `http://127.0.0.1:4173/`.

## Управление

- `WASD` / стрелки — движение
- мышь — камера
- `Shift` — бег
- `Space` — прыжок
- ЛКМ — атака
- ПКМ — блок
- `E` — взаимодействие
- `Q` — фракционная способность
- `F` — следующий приказ отряду
- `H` — перевязка
- `Esc` — пауза, сохранение и выход

Сохранение хранится локально в браузере через `localStorage`.

## Публикация

У проекта нет сборки и backend. Для публикации достаточно разместить содержимое этой директории на GitHub Pages. Three.js загружается как ES-модуль с jsDelivr; остальные ассеты лежат локально.
