# КОРОВАНЫ — 3Д-экшон (вариант Opus 5)

Браузерная 3D-игра по классическому ТЗ Кирилла. Три играбельные стороны, четыре зоны,
густой лес с подменой картинок на 3-хмерные деревья, отрубание конечностей, протези,
лавки как в Daggerfall и, конечно, корованы — их можно грабить.

Ни сборки, ни зависимостей в репозитории: чистые ES-модули + three.js с CDN.
Папку можно класть на GitHub Pages как есть.

## Запустить

```bash
cd Opus-5
python3 -m http.server 8080
# открыть http://127.0.0.1:8080/
```

Открывать файл напрямую (`file://`) нельзя — ES-модулям нужен http.
На GitHub Pages достаточно включить Pages для ветки: игра будет по адресу
`https://<пользователь>.github.io/<репозиторий>/Opus-5/`.

## Управление

| Клавиша | Что делает |
|---|---|
| WASD | ходить |
| Shift | бежать (тратит выносливость) |
| Space | прыгать |
| ЛКМ | атака (меч/секира — размах, лук/арбалет/посох — выстрел) |
| E | говорить, обыскать труп, ограбить корован, торговать, отдохнуть |
| R | бинты (остановить кровь) |
| Q | зелье лечения |
| F | приказ отряду «за мной»; у своей базы — нанять бойца (60 золотых) |
| T | приказ «в атаку» — отряд идёт на вражескую базу вместе с вами |
| 1 / 2 | взять ближнее / дальнее оружие |
| I | рюкзак и состояние тела |
| M | карта и быстрое перемещение |
| Esc | пауза, сохранение, загрузка |

## Что сделано по ТЗ

**Три стороны.**
- **Лесные эльфы** — живут в густом лесу в домиках деревяных на сваях. На них набигают
  солдаты дворца и слуги Злого. Старейшина даёт задания, в том числе грабить корованы.
- **Охрана дворца** — надо слушаться командира: защищать дворец от Злого, шпионов и
  партизанов эльфов, ходить на набеги на эльфов и в горы, сопровождать корованы.
- **Злой… (имя не придумано)** — сам себе командир. Нанимает войско в форте (F),
  приказывает ему напасть на дворец и идёт в атаку сам (T). Иногда нападают
  шпионы и партизаны эльфов.

**4 зоны на одной карте** (2×2 км, без загрузок между зонами):
1. Земли людей — нейтралы, городок, оружейник, лекарь-протезист, торговец, постоялый двор;
2. Земли императора — дворец со стенами, башнями, донжоном и гарнизоном;
3. Лес эльфов — самый густой лес и деревня на сваях;
4. Горы Злого — скалы и старый форт с обвалившимися стенами.

**Движок с подменой деревьев.** Вдали деревья — картинкой (билборды, всегда повёрнуты к
игроку), ближе 66 метров они превращаются в 3-хмерные со стволом, кроной и тенью.
Обе группы — инстансинг, переключение идёт по сетке ячеек вокруг игрока, поэтому
14 000 деревьев не роняют кадры. Проверено: в чаще одновременно ~160 трёхмерных
деревьев и ~2200 картинок.

**Корованы.** По тракту «городок людей → дворец» ходят обозы: три повозки с лошадьми,
тюками и охраной. Ограбить — подойти и нажать E (охрана будет против). За охрану
дворца, наоборот, дают задание довести корован целым.

Найти корован специально сделано просто, иначе главная строчка ТЗ не работает:

- первый обоз выходит на тракт на 8-й секунде, и если тракт опустел — следующий идёт
  через 25 секунд, так что грабить всегда есть кого;
- в HUD всегда висит строка «🐫 КОРОВАН — N м на юго-восток» с любого конца карты;
- на головной повозке стоит одиннадцатиметровый шест с красно-золотым знаменем —
  его видно поверх леса и холмов;
- на карте (M) нарисован сам тракт и жёлтая точка обоза;
- тракт проложен вдоль южной опушки эльфийского леса (≈550 м от деревни, ≈90 м от
  края чащи), чтобы эльфам было на кого засадить, а не бежать через полкарты.

**Увечья — главное из ТЗ.** Убить можно не только совсем:
- **отрубить руку** — идёт кровь, если не перевязать (R) или не дойти до лекаря, персонаж
  умрёт; урон в бою падает; можно поставить протез;
- **выколоть глаз** — не смертельно, но пол-экрана не видно; оба глаза — почти слепота;
  помогает купленный стеклянный глаз;
- **отрубить ногу** — либо истечь кровью, либо ползать (камера у земли, скорость 1.5),
  либо котаться на купленной коляске (прыгать нельзя, в гору не заедет), либо —
  самое хорошее — поставить протез и снова ходить и прыгать.

Всё то же самое работает и на врагах: у них отлетают руки и ноги, отрубленная конечность
падает на землю отдельным объектом, труп тоже 3д — заваливается на землю и остаётся
лежать, его можно обыскать.

**Покупать можно как в Daggerfall.** Лавки в каждой зоне: оружие, броня, стрелы, зелья,
бинты, протези рук и ног, стеклянный глаз, коляска, услуги лекаря. Всё, что есть в
рюкзаке, продаётся за полцены. Есть быстрое перемещение по разведанным зонам.

**Сохранятся можно.** Esc → «Сохранится» (или отдых на постоялом дворе). Сохранение
лежит в localStorage: фракция, золото, вещи, задание, звание и все увечья.

## Устройство кода

```
index.html      разметка HUD и всех экранов
style.css       оформление
js/config.js    зоны, фракции, предметы, лавки, стартовое снаряжение
js/util.js      шум, математика, мелкие хелперы
js/terrain.js   высоты, биомы, дороги, меш земли
js/forest.js    лес и подмена уровней детализации (картинка ⇄ 3D)
js/props.js     дворец, деревня эльфов, городок людей, старый форт
js/actors.js    тела из частей, ИИ, отрубание конечностей, трупы
js/player.js    ходьба, прыжки, увечья, протези, рюкзак
js/caravan.js   корованы
js/quests.js    задания и звания трёх сторон
js/ui.js        HUD, лавки, рюкзак, диалоги, карта
js/save.js      сохранения
js/audio.js     звуки на WebAudio (без файлов)
js/game.js      сборка всего: бой, приказы, события мира, цикл
```

## Чего нет

- Заходить внутрь домов нельзя — постройки цельные, торговля идёт снаружи у прилавка.
- Смены дня и ночи нет, погоды тоже.
- Управление только клавиатура + мышь, тачскрин не поддержан.
- Переход «картинка → 3D» происходит скачком на 66 метрах, без плавного растворения.
