# КОРОВАНЫ — игра по ТЗ Кирилла

> «Здраствуйте. Я, Кирилл. Хотел бы чтобы вы сделали игру, 3Д-экшон суть такова...
> Можно грабить корованы... P.S. Я джва года хочу такую игру.»

Эксперимент: одно и то же легендарное ТЗ выдаётся разным моделям,
каждая делает свой вариант игры в отдельной директории.

**Играть:** https://rai220.github.io/korovany/

## Варианты

| Модель | Директория | Стек |
|---|---|---|
| Fable 5 | [`fable_5/`](fable_5/) | Three.js, ванильный JS, без сборки |
| Opus 4.8 | [`Opus-4.8/`](Opus-4.8/) | Three.js, ванильный JS, без сборки |

## Запуск локально

```bash
python3 -m http.server 8123
# открыть http://localhost:8123/
```

Все варианты — чистая статика, деплоится на GitHub Pages из корня ветки `main`.
