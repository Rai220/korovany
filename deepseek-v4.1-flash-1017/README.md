# Корованы: Четыре Земли

Браузерный 3D-экшен о пограничье, трёх играбельных сторонах, густом лесе, караванах, отрубленных конечностях и протезах.

**Модель запуска:** `deepseek-v4.1-flash-1017`

Точное имя модели взято из конфигурации и метаданных текущего запуска Codex (`/Users/knkrestnikov/.codex/deepseek.config.toml`, `session_meta`). Оно указано в `<title>`, в заголовке игры на стартовом экране, в HUD, на карте мира и в этом README. Каталог игры назван безопасным вариантом того же имени: `deepseek-v4.1-flash-1017`.

## Запуск

Игра полностью статическая: HTML + CSS + один JavaScript-файл, без сборки, внешних библиотек, шрифтов, изображений и сетевых запросов.

### Локально

Откройте `index.html` в современном браузере (Chrome, Edge, Firefox, Safari). Для проверки по HTTP можно запустить из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем открыть:

```text
http://localhost:8000/deepseek-v4.1-flash-1017/
```

Все пути относительные (`style.css`, `game.js`), поэтому игра работает и при открытии файла напрямую, и при размещении в подкаталоге.

### GitHub Pages

1. Опубликуйте репозиторий через Settings → Pages (Deploy from a branch).
2. Точка входа — `deepseek-v4.1-flash-1017/index.html`.
3. Игра будет доступна по адресу вида `https://<user>.github.io/<repo>/deepseek-v4.1-flash-1017/`.

Серверная часть, база данных и API не нужны.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `W` `A` `S` `D` |
| Бег | `Shift` |
| Обзор камеры | мышь после клика по полю, либо `←` `→` `↑` `↓` |
| Атака | `ЛКМ` (можно удерживать) |
| Блок | `ПКМ` |
| Прыжок | `Space` |
| Взаимодействие, торговля, приказ командира, грабёж | `E` |
| Военный совет злодея / сбор эльфийских партизан | `V` |
| Состояние, раны и сумка | `Tab` |
| Карта мира | `M` |
| Бинт / эликсир / коляска | `1` / `2` / `3` |
| Сохранить / загрузить | `F6` / `F9` |
| Пауза | `P` или `Esc` |
| Приближение камеры | колесо мыши |

Стартовый экран: выберите одну из трёх карт — лесной эльф, стража дворца или злодей Морвейн. Если есть сохранение, доступна кнопка загрузки.

## Реализованные возможности

### Три играбельные стороны

- **Лесные эльфы.** Старт в густом лесу у деревянной деревни. Имперские каратели и налётчики Морвейна нападают на дома. Можно отбивать набеги, собирать партизан (`V`), грабить караваны и уходить в свободную игру.
- **Стража дворца.** Дворец окружён стеной с воротами и башнями. Командир Арден у южных ворот выдаёт приказы (`E`): ловить лазутчиков, бить эльфийских партизан или идти в набег на лес. Есть показатель верности: удары по своим и грабёж торговцев снижают его, выполнение приказов повышает.
- **Злодей Морвейн.** Старый форт в Мглистых горах. Клавиша `V` открывает военный совет: штурм дворца, набег на эльфов, грабёж караванов или оборона форта. Войско идёт за игроком; приказ формирует новую цель.

### Четыре зоны на одной карте

1. **Вольная Марка** — нейтральная зона людей: деревня, лавка, таверна, колодец, торговцы.
2. **Империя** — дворец императора: стены, ворота, башни, казармы и стража.
3. **Лесное княжество** — густой лес и деревянные дома эльфов.
4. **Мглистые горы** — старый форт злодея, каменные стены и горные породы.

Между зонами проложены дороги; по ним движутся караваны с охраной.

### Лес с LOD

- Лес генерируется детерминированно: более 800 деревьев, у края карты — плотная кайма.
- Дальние деревья рисуются как предварительно созданные 2D-спрайты (billboard).
- При приближении к дереву ближе 53 метров оно автоматически заменяется на объёмную 3D-модель из ствола и нескольких конусов кроны. Это видно при движении через лес.

### 3D-сцена и персонажи

- Собственный программный 3D-рендерер на Canvas 2D: перспективная проекция, отсечение по ближней плоскости, painter's algorithm, туман, тени, небо, горы, костры и частицы.
- Дома, крепости, башни, стены, колодцы, палатки и повозки собираются из 3D-примитивов.
- Враги, союзники, торговцы и игрок — объёмные человечки из 3D-блоков с анимацией ходьбы, удара и оружием.
- Убитые остаются **3D-трупами** на земле: тело, голова, конечности, оружие и лужа крови.
- Прыжки с гравитацией, бег с выносливостью, блокировка удара, удержание атаки.

### Бой и увечья

- Кровь, вспышки урона, тряска камеры, частицы, полоски здоровья противников.
- При попадании есть шанс потерять **руку**, **глаз** или **ногу**.
- **Рука:** урон падает примерно до 37%, начинается кровотечение. Бинт останавливает кровь, лекарь лечит, протез возвращает силу.
- **Глаз:** левая половина экрана затемняется и перекрывается. Повязка уменьшает затемнение, протез глаза полностью возвращает обзор.
- **Нога:** можно медленно ползти, купить и разложить боевую коляску (`3`) или поставить протез, вернув бег и прыжки.
- Кровотечение продолжается, пока его не остановят бинтом, лекарем или протезом. Без лечения герой умирает.
- Смерть показывает отдельный экран с загрузкой сохранения, новой жизнью или выходом в меню.

### Экономика, торговля и грабёж

- У торговцев можно купить бинты, эликсиры, протезы руки/глаза/ноги, коляску, повязку, броню и улучшенный клинок.
- Лекарь за 25 золота полностью восстанавливает HP и останавливает кровотечение.
- Золото начисляется за убийства, обыск тел и ограбление караванов.
- Грабёж каравана (`E` рядом с повозкой) даёт золото, злит охрану и ухудшает отношение людей; у стражи дополнительно падает верность.

### Сохранения

- Сохраняется фракция, позиция, здоровье, раны, протезы, золото, инвентарь, актёры, трупы, караваны, задания, репутация, верность и приказы.
- `F6` — сохранить, `F9` — загрузить.
- Есть автосохранение при выполнении задания, покупке, грабеже и раз в ~28 секунд.
- Используется `localStorage` браузера. Сохранение привязано к источнику страницы.

### Интерфейс и карта

- HUD: здоровье, выносливость, кровотечение, золото, раны и протезы.
- Мини-карта, компас, название текущей зоны, журнал текущего поручения.
- Большая карта (`M`) с зонами, дорогами, зданиями, караванами, союзниками, врагами и игроком.
- Подсказки взаимодействия, уведомления, экран паузы и справка по управлению.

## Проверка

В игре есть встроенный автотест, который запускается в headless-браузере и проверяет 23 механики: зоны, генерацию леса, LOD, 3D-труп, добычу, ранения, все три протеза, коляску, задания, грабёж, сохранение/загрузку, приказы злодея и прыжок.

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --no-sandbox --disable-gpu \
  --virtual-time-budget=7000 --dump-dom \
  "file:///path/to/deepseek-v4.1-flash-1017/index.html?selftest=1"
```

В DOM будет строка `SELFTEST OK · 23/23 проверок пройдено` и подробный список.

Также вручную/через CDP проверены: загрузка страницы, отрисовка canvas, движение `W`, поворот камеры, атака `ЛКМ`, открытие магазина через `E`, покупка кнопкой, затемнение глаза, протез глаза, карта `M`, сохранение `F6`, отсутствие JS-исключений и стабильные 60 fps в тестовом окружении.

## Известные ограничения

- Это программный Canvas-3D-рендерер, а не WebGL/физический движок: нет честного освещения с тенями, скелетной анимации и точной физики столкновений. Объекты сортируются по глубине, поэтому у крупных пересекающихся геометрий возможны редкие артефакты порядка отрисовки.
- Столкновения упрощены до окружностей и прямоугольников; персонажи не умеют обходить препятствия по навигационной сетке и могут застревать у сложных стен.
- ИИ противников простой: обнаружение по радиусу, преследование, ближний бой и патрулирование. Нет сложного тактического поведения, стрельбы из лука и осадных орудий.
- Квесты — небольшой линейный набор с повторяемой свободной целью; побочных сюжетных линий и диалогового дерева нет.
- Один слот сохранения в `localStorage`; сохранение не синхронизируется между браузерами и может быть недоступно в приватном режиме.
- Управление рассчитано на клавиатуру и мышь; сенсорные экраны и геймпады не поддерживаются.
- Многопользовательского режима, звуковых файлов и музыкального сопровождения нет.
- Мир не разделён на отдельные загружаемые локации: все четыре зоны находятся на одной карте и всегда активны в пределах радиуса отрисовки.
